\section{Introduction}
Recall that given a string with nontrivial mass, when a pulse / mechanical wave is sent through the string, the speed of the pulse is dependent both on $\mu$ - string's density, or mass per unit length (unit: kg/m) - and the tension $T$ (unit: N) applied on the string itself.  Based on suitable approximation and model, the proposed speed of the pulse is given by $v=\sqrt{\frac{T}{\mu}}$.

The goal is to figure out the relationship between the velocity of wave propogation, and its tension force. It is also aimed to figure out the coefficient $\mu$ based on the measured data.

\section{Quantities to Measure and Methods of Measurement}
There are three types of the experiments. 

For the setup with manual measurement, it's measuring the time (unit: s) it takes for a wave to propogate back and forth in a string, which a total of $3$ trials of measurement are performed.

\hfil

For the setup with function generator, two experiments are involved:

The second experiment using function generator is measuring first resonance frequency (unit: Hz) for varying masses (unit: kg), which represents varying tension (unit: T). Each chosen mass is measured with a total of $3$ trials.

The third experiment however, instead of measuring the resonance frequency with multiple trials, for each fixed mass, it performs one measurement at each resonance frequency, until it is no longer observable. More precisely, fixing each mass, keep measuring the $1^\text{st},2^\text{nd},...,n^\text{th}$ resonance frequency, until it's no longer observable (which normally happened at $n=6,7$).

\section{Experimental Procedure}
\subsection{Experiment with Manual Setup}
The goal for this section is to get a rough / general observation about the wave propogation, instead of performing a precise measurement.

The following procedure is performed:
\begin{itemize}
    \item[1.] Measure the mass used for tension, and hang the mass at the end of the string that's at the pully's side.
    \item[2.] Gently tap the string on the other end (that is taped), but with large enough amplitude that can be observed and recorded by the camera.
    \item[3.] For the whole process in Step 2, record using the slow-motion camera till the time that the wave has traveled back to the initial starting point.
    \item[4.] Repeat step 2 to 3 for the total of 3 times.   
\end{itemize}

\hfil
\subsection{Experiment with Function Generator}
\subsubsection{Experiment Measuring 1st Resonance Frequency}
The goal for this section is to derive the velocity of the wave using the resonance frequency, and further derive the string's mass per unit length constant $\mu$ using the known velocity and tension.

The following procedure is performed:
\begin{itemize}
    \item[1.] Fix a mass used for tension, measure the mass, and hang it at the end of the string (on the pully's side).
    \item[2.] Start the function generator, and let the string vibrator vibrate the string.
    \item[3.] Tweak the output frequency on the function generator, until the first resonance is observed (which requires the string to have stable amplitude, and the pully is not oscillating back and forth; or more precisely, when the string has a fixed point at the end). Record this first resonance frequency displayed on the function generator.
    \item[4.] Repeat Step 2 to 3 for a total of 3 trials for the fixed mass.
    \item[5.] Change the mass mentioned in Step 1, and repeat Step 2 to 4 for each desired mass.
\end{itemize}

\subsubsection{Experiment Measuring nth Resonance Frequency}
The goal for this section is to observe multiple resonance frequency when fixing a specific tension force, observe the change of wavelength under different frequencies, and also see if the wave velocity is independent from the resonance frequency (when fixing tension).

The following procedure is performed:
\begin{itemize}
    \item[1.] Fix a mass used for tension, measure the mass, and hang it at the end of the string (on the pully's side).
    \item[2.] Start the function generator, and let the string vibrator vibrate the string.
    \item[3.] Tweak the output frequency on the function generator, until the first resonance is observed (which requires the string to have stable amplitude, and the pully is not oscillating back and forth; or more precisely, when the string has a fixed point at the end). Record this first resonance frequency displayed on the function generator.
    \item[4.] Repeat Step 3 inductively for each $n^\textmd{th}$ resonance frequency (for $n=2,3,...$) until the resonance is no longer observable.
    \item[5.] Change the masses to other ones await to be measured, and repeat Step 2 to 4 for the desired mass.
\end{itemize}

\subsection{Experiment with Function Generator - 1st Resonance Frequency}
First, recall that based on the claimed relation, velocity $v=\lambda f$, where $\lambda$ is the wavelength (unit: m) and $f$ is the frequency (unit: Hz). Since the string length in this case is $l=0.865$ m (with $\delta l=0.0005$ m, by the limitation of meter stick), then when reaching the first resonance frequency (where there are no fixed point, and only one peak / valley each time), then the string length represents $\frac{\lambda}{2}$, showing that $\lambda=2l=1.730$ m (with $\delta \lambda=\delta l\cdot \sqrt{(\frac{\partial \lambda}{\partial l})^2} = 2\delta l = 0.001$ m). 

Hence, with $v=\lambda f$, the propogation of uncertainty of $v$ is given by the following:
\begin{align}
    \delta v= \sqrt{\left(\frac{\partial v}{\partial \lambda}\right)^2(\delta\lambda)^2+\left(\frac{\partial v}{\partial f}\right)^2(\delta f)^2} = \sqrt{(\lambda\cdot \delta f)^2 + (f\cdot \delta\lambda)^2} 
\end{align}
